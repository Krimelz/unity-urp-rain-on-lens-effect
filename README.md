# Requirements

Unity 6.3+ and URP 17.3+ version.

# Features

* Works in global and local volume.

# Installation

The recommended way to install the package is through the package manager in Unity (UPM).
Before installing, make sure that URP is installed and correctly set up in your project.
Then you can proceed to install this package:

1. Inside Unity, go to "Window"-> "Package Manager".
2. Once the window is opened, go to the "+" symbol at the top left corner, and select "Install package from git URL".
3. Write the following URL: https://github.com/Krimelz/unity-urp-rain-on-lens-effect.git and click install.
